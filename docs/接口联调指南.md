## 📦 已封装的 API 接口

### 1. 用户认证 (`authApi`)

```javascript
import { authApi } from '@/services/api'

// 登录
const { token, user } = await authApi.login({ email, password })

// 注册
const { token, user } = await authApi.register(data)

// 获取当前用户
const userInfo = await authApi.getCurrentUser()

// 退出登录
await authApi.logout()

// 修改密码
await authApi.changePassword({ oldPassword, newPassword })
```

### 2. 文档管理 (`documentApi`)

```javascript
import { documentApi } from '@/services/api'

// 获取文档列表
const { list, total } = await documentApi.getList({ page, pageSize, category, keyword })

// 获取文档详情
const doc = await documentApi.getDetail(id)

// 创建文档
const newDoc = await documentApi.create({ title, content, category, tags, status })

// 更新文档
await documentApi.update(id, { title, content, ... })

// 删除文档
await documentApi.delete(id)

// 点赞/取消点赞
await documentApi.like(id)
await documentApi.unlike(id)

// 收藏/取消收藏
await documentApi.favorite(id)
await documentApi.unfavorite(id)

// 获取版本历史
const versions = await documentApi.getVersions(id)

// 回滚版本
await documentApi.rollback(id, versionId)
```

### 3. 搜索 (`searchApi`)

```javascript
import { searchApi } from '@/services/api'

// 搜索文档
const { list, total, highlight } = await searchApi.search(keyword)

// 获取推荐文档
const recommendations = await searchApi.recommend()

// 获取热门搜索
const hotSearches = await searchApi.getHotSearches()

// 获取/清除搜索历史
const history = await searchApi.getSearchHistory()
await searchApi.clearSearchHistory()
```

### 4. 评论 (`commentApi`)

```javascript
import { commentApi } from '@/services/api'

// 获取评论列表
const comments = await commentApi.getList(documentId)

// 创建评论
const comment = await commentApi.create(documentId, { content })

// 回复评论
await commentApi.reply(documentId, commentId, { content })

// 删除评论
await commentApi.delete(documentId, commentId)

// 点赞评论
await commentApi.like(documentId, commentId)
```

### 5. 积分 (`pointsApi`)

```javascript
import { pointsApi } from '@/services/api'

// 获取积分排行
const ranking = await pointsApi.getRanking({ limit })

// 获取个人积分明细
const { list, total } = await pointsApi.getDetail()

// 获取积分规则
const rules = await pointsApi.getRules()
```

### 6. 用户 (`userApi`)

```javascript
import { userApi } from '@/services/api'

// 获取用户信息
const profile = await userApi.getProfile(userId)

// 更新用户信息

// 获取用户统计
```

## 🎯 在组件事件中使用 API

### 示例 1：登录表单提交

```javascript
// src/pages/Login/index.jsx
const handleLogin = async (values) => {
  setLoading(true)
  try {
    // 调用登录接口
    const { token, user } = await authApi.login(values)
    
    // 保存用户状态
    login(user, token)
    
    message.success('登录成功')
    navigate('/')
  } catch (error) {
    console.error('登录失败:', error)
    // 错误处理已在 request.js 拦截器中统一处理
  } finally {
    setLoading(false)
  }
}
```

### 示例 2：文档列表加载

```javascript
// src/pages/document/List.jsx
const fetchDocuments = async () => {
  setLoading(true)
  try {
    const { list, total } = await documentApi.getList({
      page,
      pageSize,
      keyword,
      category,
    })
    setDocuments(list)
    setTotal(total)
  } catch (error) {
    console.error('获取文档列表失败:', error)
  } finally {
    setLoading(false)
  }
}

useEffect(() => {
  fetchDocuments()
}, [page, pageSize, category])
```

## 🔐 认证与权限

### Token 自动注入

`request.js` 会自动在请求头中添加 Token：

```javascript
// 请求拦截器
request.interceptors.request.use((config) => {
  const token = useUserStore.getState().token
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})
```

### 401 自动处理

未登录或 Token 过期会自动跳转登录页：

```javascript
// 响应拦截器
case 401:
  message.error('未登录或登录已过期')
  useUserStore.getState().logout()
  setTimeout(() => {
    window.location.href = '/login'
  }, 1000)
```

## 🛠️ 联调步骤

### 1. 启动后端服务

确保后端服务运行在 `http://localhost:8080`

### 2. 配置代理（已配置）

`vite.config.js` 已配置代理：

```javascript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/api/, '')
    }
  }
}
```

### 3. 修改环境变量

创建 `.env.development`：

```bash
VITE_API_BASE_URL=http://localhost:8080/api
```

### 4. 切换 Mock 开关

将所有页面中的 `useMock` 改为 `false`：

```javascript
const useMock = false
```

### 5. 启动前端

```bash
npm run dev
```

## 🐛 常见问题

### 1. 跨域错误

**现象**: 控制台报 `Access-Control-Allow-Origin` 错误

**解决**: 
- 后端配置 CORS 允许跨域
- 或使用 Vite 代理（已配置）

### 2. 401 未授权

**现象**: 所有请求都返回 401

**解决**:
- 检查是否已登录
- 检查 Token 是否正确
- 检查后端 Token 验证逻辑

### 3. 接口路径错误

**现象**: 404 Not Found

**解决**:
- 检查 `baseURL` 配置
- 检查接口路径是否匹配
- 检查代理配置中的 `rewrite` 规则
