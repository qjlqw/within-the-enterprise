## 1. 权限 Hook

### usePermission

```javascript
import { usePermission } from '@/hooks/usePermission'

const { 
  hasPermission,    // 检查权限
  hasAnyRole,       // 检查任意角色
  hasAllRoles,      // 检查所有角色
  isAdmin,          // 是否管理员
  isEditor,         // 是否编辑者
  user,             // 用户信息
  isAuthenticated   // 是否已认证
} = usePermission()
```

### 使用示例

```javascript
import { usePermission } from '@/hooks/usePermission'

function MyComponent() {
  const { hasPermission, isAdmin } = usePermission()
  
  return (
    <div>
      {/* 检查单个角色 */}
      {hasPermission('admin') && <button>管理后台</button>}
      
      {/* 检查多个角色（任意一个） */}
      {hasPermission(['admin', 'editor']) && (
        <button>编辑内容</button>
      )}
      
      {/* 使用快捷方法 */}
      {isAdmin() && <button>管理员专属</button>}
    </div>
  )
}
```

## 2. 权限组件

### Permission 组件

```javascript
import Permission from '@/components/Permission'

// 基础用法 - 只有管理员可见
<Permission roles="admin">
  <Button>删除</Button>
</Permission>

// 多个角色 - 管理员或编辑者可见
<Permission roles={['admin', 'editor']}>
  <Button>编辑</Button>
</Permission>

// 禁用模式 - 无权限时显示禁用状态
<Permission roles="admin" mode="disabled">
  <Button>删除</Button>
</Permission>

// 自定义 fallback
<Permission 
  roles="admin" 
  fallback={<span>暂无权限</span>}
>
  <Button>删除</Button>
</Permission>
```

## 3. 权限按钮

### AuthButton 组件

```javascript
import AuthButton from '@/components/AuthButton'

// 基础用法 - 无权限时隐藏
<AuthButton roles="admin">
  删除
</AuthButton>

// 禁用模式 - 无权限时按钮禁用
<AuthButton roles="admin" mode="disabled">
  删除
</AuthButton>

// 多个角色
<AuthButton roles={['admin', 'editor']}>
  编辑
</AuthButton>

// 自定义 fallback
<AuthButton 
  roles="admin" 
  fallback={<Button disabled>无权限</Button>}
>
  删除
</AuthButton>

// 传递其他 Button 属性
<AuthButton 
  roles="admin"
  type="primary"
  danger
  onClick={handleDelete}
>
  删除
</AuthButton>
```

## 4. 实际示例

### 示例 1：文档列表页的操作按钮

```javascript
// src/pages/document/List.jsx
import { usePermission } from '@/hooks/usePermission'
import AuthButton from '@/components/AuthButton'

function DocumentList() {
  const { hasPermission, user } = usePermission()
  
  const columns = [
    {
      title: '操作',
      render: (_, record) => (
        <Space>
          {/* 查看 - 所有人可见 */}
          <Button onClick={() => navigate(`/document/${record.id}`)}>
            查看
          </Button>
          
          {/* 编辑 - 作者或管理员可见 */}
          <AuthButton 
            roles={['admin', 'editor']}
            mode="hidden"
            onClick={() => navigate(`/document/editor/${record.id}`)}
          >
            编辑
          </AuthButton>
          
          {/* 删除 - 仅管理员可见 */}
          <AuthButton 
            roles="admin"
            mode="disabled"
            danger
            onClick={() => handleDelete(record.id)}
          >
            删除
          </AuthButton>
        </Space>
      )
    }
  ]
  
  return <Table columns={columns} />
}
```

## 5. 角色定义

### 系统角色

| 角色 | 标识 | 说明 | 权限 |
|------|------|------|------|
| 管理员 | `admin` | 系统管理员 | 所有权限 |
| 编辑者 | `editor` | 内容编辑者 | 创建/编辑/删除自己的文档 |
| 普通用户 | `user` | 普通用户 | 查看/评论/点赞 |

### 用户数据结构

```javascript
{
  id: 1,
  name: '张三',
  email: 'zhangsan@company.com',
  roles: ['admin'],  // 角色数组，支持多角色
  department: '技术部',
  points: 2580
}
```

## 6. 最佳实践

### ✅ 推荐做法

```javascript
// 1. 使用权限组件包裹操作按钮
<AuthButton roles="admin" onClick={handleDelete}>
  删除
</AuthButton>

// 2. 在 Hook 中集中处理权限逻辑
const { hasPermission } = usePermission()
const canEdit = hasPermission(['admin', 'editor']) || isAuthor

// 3. 使用语义化的权限检查
{isAdmin() && <AdminPanel />}
{isEditor() && <EditorTools />}
```

### ❌ 避免做法

```javascript
// 1. 避免硬编码角色判断
{user?.roles?.includes('admin') && ...}  // ❌

// 2. 避免在多处重复权限逻辑
const isAdmin = user?.roles?.[0] === 'admin'  // ❌

// 3. 避免直接修改用户状态
user.roles.push('admin')  // ❌
```

## 8. 常见问题

### Q1: 如何添加新角色？

在 `userStore.js` 中修改用户数据，添加新角色标识：

```javascript
roles: ['admin', 'new_role']
```

### Q2: 如何控制接口权限？

在前端校验的同时，后端也需要进行权限验证：

```javascript
// 前端
const { hasPermission } = usePermission()
if (!hasPermission('admin')) {
  message.error('无权限')
  return
}
await documentApi.delete(id)  // 后端也会验证
```

### Q3: 权限变更后如何刷新？

重新登录或更新用户状态：

```javascript
const updateUser = useUserStore((state) => state.updateUser)
updateUser({ roles: ['admin'] })
```
