# 知识助手接入与验收

## 实现与环境

已实现只读知识服务、LangChain 工具循环、会话 API、SSE、停止、来源校验和 `/agent` 页面。
Agent 仅可访问 `published` 文档，工具不会增加浏览量；第一版使用关键词检索与单进程内存会话。

安装版本以 lockfile 为准：Node 22.23.2、LangChain 1.5.10、@langchain/core 1.2.9、@langchain/openai 1.5.8。
已根据安装包类型定义及本机兼容协议测试核验 `createAgent`、`tool`、`createMiddleware`、`streamEvents(version: 'v2')` 和 `AbortSignal`。
兼容协议测试运行真实 SDK 与工具，但不等同于通义千问云端模型验收。

## 配置与启动

使用 Node 22 LTS（>=22.12）。本次执行环境的系统 Node 为 20.18，已在不修改系统安装的情况下，
将 Node 22 放在项目忽略目录 `.runtime/node_modules/node/bin/node.exe`。
Windows 当前工作区可在终端执行 `$env:PATH = "$PWD\.runtime\node_modules\node\bin;$env:PATH"` 后运行以下命令。

```sh
npm install
npm --prefix server install
npm --prefix server run dev
# 另一个终端
npm run dev
```

也可在根目录运行 `npm run dev:full` 同时启动前后端；该入口会自动避让已占用端口，并打印实际访问地址。

在 `server/.env` 中配置下列值。地域示例为中国内地，其他地域必须使用对应账号的服务地址。
`qwen-plus` 是待验证的模型候选，并未在本次执行环境完成云端工具调用验证。

```dotenv
AGENT_ENABLED=true
LLM_MODEL=qwen-plus
LLM_API_KEY=<在本机填写>
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AGENT_RUN_TIMEOUT_MS=60000
AGENT_MAX_TOOL_CALLS=6
AGENT_MAX_MODEL_CALLS=8
AGENT_MAX_OUTPUT_TOKENS=2000
AGENT_MAX_SESSIONS=1000
```

密钥不得放在前端环境变量或源码中。模型适配固定采用 `@langchain/openai` 的 Chat Completions 协议，
使用 `enable_thinking=false`；是否适用于具体模型、地域与账号必须通过真实冒烟验证。
未启用或配置缺失时，会话管理仍可使用，发送消息返回明确的 503；文档业务仍可正常启动。
不配置外部追踪平台。若运行环境原先开启过 LangSmith，请清除 `LANGSMITH_TRACING`/`LANGCHAIN_TRACING_V2`，
避免 SDK 根据环境变量上传对话。

## 运行约束

每轮 4000 字符输入、6 次工具、8 次模型、60 秒超时；模型每次输出上限 2000 token，整轮正文最多 16000 字符。
暂时性 429/5xx 只在尚未输出正文时重试一次，重试计入调用预算；SDK 内置自动重试关闭。
工具返回正文累计最多 24000 字符，单次读取最多 6000 字符，搜索默认 5 条、最多 10 条，每条片段最多 500 字符。

会话按用户隔离；每用户最多 20 个会话，每会话最近 10 轮，模型历史进一步限制在约 24000 字符预算内。
每用户每分钟最多 10 次提交，最多一个正在执行的回答。幂等消息 ID 在会话生命周期内保留，
每会话累计 200 次提交后需新建会话。会话闲置 24 小时过期，进程总容量默认 1000。
文档版本、发布状态或正文变化后清除相关历史与旧摘要；取消、失败的回答不进入后续模型历史。

页面通过现有 Bearer Token 登录态加载会话，聊天正文不保存到 localStorage。
原始 HTML、图片及模型生成的链接均不作为可执行内容展示，文档引用统一跳转到 `/document/:id`。

## 部署前置条件

SSE 代理需要关闭缓冲与缓存，读取超时必须大于整轮超时。例如 Nginx：

```nginx
location /api/agent/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 90s;
}
```

内存会话、用户和文档均不保证重启恢复或多实例一致性。正式部署需要持久存储、共享限流与取消机制。
原有文档 HTTP 读取入口仍存在草稿可见性问题，回滚接口仍需补齐作者/管理员授权；
本次按计划完成 Agent 演示范围，未将这些既有权限补齐混入本轮变更。
接入真实企业数据前，必须统一既有路由权限、更换 JWT 密钥、限制 CORS 并明确外发资料范围。
