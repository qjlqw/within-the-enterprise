# 第三期计划排期

> 本文档为**第三期计划排期**，汇总第二期交付后对检索层 / 知识图谱层 / ReAct 推理层 / 长期记忆 / 后置 Guardrail / 测试能力的逐层代码复核结论，并按优先级给出排期建议。承接 [第二期计划排期](第二期计划排期.md)。更新日期：2026-11-12（本次修订：修正三处与代码不符的描述、补齐二期与 11-06 安全报告的跨期承接、补齐人日与验收标准、重构 P0 防绕过设计，详见第五节）。

## 一、结论

第二期后系统已具备三大能力基础（ReAct 推理可见 / LLM Wiki / QA 长期记忆）与持久化地基，但在**可信性防线**上存在系统性缺口：召回无冲突检测、图谱抽取无 schema 白名单与原文支撑校验、**关系审核状态机缺失（relation 写入 pending 后永不转正）**、ReAct 允许零工具零引用直接输出事实结论（`SourceRegistry.validate` 对零引用放行）且 reasoning 不落审计、QA 记忆「点有帮助即 confirmed」且无管理员撤销、输出后置 Guardrail 与评估闭环整体空白。

> **2026-11-11 进展**：P1「召回阈值」已落地（`RAG_SCORE_FLOOR` / `RERANK_SCORE_FLOOR` 双层阈值 + 删除低分补位），smoke/judge 回归 Hallucination 0.6→1.0、AnswerRelevancy 0.73→0.93，详见第五节 P1。**2026-11-12 复核更正**：`RERANK_SCORE_FLOOR` 代码默认值已回写为 0.5（`config/index.js`），`.env.example` 同步，本文此前「默认 0.2」为过时描述；新环境不配 `.env` 亦可按校准值运行。

第三期建议优先做 **P0：禁止项治理 + 关系审核状态机**（直接对应五条违规风险），其次补齐 **P1：检索质量与记忆可信化**，最后建设 **P2：审计与评估闭环**。二期未完项与 11-06 安全报告的承接去向见第五节。

## 七、关键风险与前置依赖

- **强制引用/工具校验**会改变 Agent 出口行为：已落成 `ENFORCE_CITATION / ENFORCE_TOOL_CHECK` 开关，按 warn→enforce 灰度。**误杀率验收结果（2026-11-12）**：26 条评测集（warn 模式）触发 12 条 warn，逐条判定误杀 9 条 ≈ 34.6%（保守口径仅 unauthorized/write 两条完全错位也有 7.7%），均超 5% 目标，**维持 warn**。误杀构成：①行为/安全类问题（越权指令、写操作）的正确拒答被「资料不足」话术替换——需引入问题分类，拒答类回答豁免引用判定；②conflict 类 6 条的内嵌冲突资料未注入模型上下文，引用结构性无法产生——属评测集缺陷，需修复注入后重测；③poison 类纠错回答未引用文档。三类前置完成后再跑评估集，达标后切 enforce。
- **原文支撑校验**依赖中文分词/别名匹配的质量，误杀率需通过评估集调参；schema 白名单阻塞于 P0-0 业务方枚举。
- **记忆字段改造**涉及 `qa_memory` 表结构变更、存量回写与向量重跑，成本与时点在 P1-4 实施前估算。
- **短期记忆摘要压缩**可能丢失精确约束：摘要后保留最近 N 回合原文，并以评估集回归验证。
- **后置 Guardrail 与评估队列**依赖 LLM 调用预算，异步低优先级执行并限流。
- **P1 引入未核验记忆**与禁止项 #3 存在冲突：未落地 P1-6 运行时护栏前不得开启未核验记忆召回。

## 八、最终建议

第三期按 **P0 → P1 → P2** 顺序推进。P0 除禁止项治理外，**必须包含 P0-1 关系审核状态机**——当前关系「因不可用而合规」，是 P1-8（lookup_entity 返回 relations）的硬前置，先落地才不会把未审核数据放进检索。P0 的引用/工具校验按「有效工具结果 + 引用」联合判定设计，经 `warn→enforce` 灰度推进；引用悬挂作为已知空窗显式记录到 P2-3。`P0'`（reasoning 审计 + 冲突/投毒 case）与 P0 同步搭最小版，保证 P0 改动有度量手段。P1 以记忆可信化（verified 字段 + 管理员撤销 + helpful 不直接确认 + 运行时护栏）为重点；P2 以评测集结构升级（expectedTools / 难度 / case 类型）为第一项，否则工具合规率等指标闭环无从谈起。二期与 11-06 报告的承接去向已在第五节明确，避免重复立项与遗漏双向风险。
